# Quality Rules
- 2026-07-13: First-piece inspection and hourly quality checks share `quality_parameter_master` rows as a Quality Inspection Parameter Set keyed by item, option, setup, and parameter code. Data Entry maintains the full setup parameter set in a table; legacy `first_piece_inspection_master` rows remain read-only fallback for existing data.
- 2026-07-14: Downtime reason selection uses only the shared defect/reason code list (`rejection_reason_master`, shown as Defect / downtime reason master). Do not expose or merge legacy `downtime_reason_master` rows in downtime entry dropdowns. Built-in downtime causes include D59 Electricity failure, D60 No raw material, and D61 No operator.
- 2026-07-14: Quality inspection parameter master form does not ask for parameter code, required, or status. Parameter codes are generated from row sequence (`P1`, `P2`, etc.), and saved rows remain active/required by default.
