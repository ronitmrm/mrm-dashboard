# Quotation assets

Outfit Regular, Medium, SemiBold and Bold are static weight instances of the
Google Fonts Outfit 1.100 variable font, matching the fonts embedded in the
user-supplied Quotation.pdf (Canva export, 27 August 2026).
Source: https://github.com/google/fonts/tree/main/ofl/outfit
License: Outfit-OFL.txt.

The letterhead and stylized preparer name are cropped from that supplied PDF
at 432 dpi. They contain only the fixed branding/preparer artwork, without
sample customer, price or commercial terms. The textual job title remains
Engineering Lead, as explicitly requested.

Body/table text is 10 pt; section headings/footer 12 pt; title 32.007 pt with
the reference's measured kerning. The renderer preserves centred item cells
and repeats the same branding on continuation pages.
